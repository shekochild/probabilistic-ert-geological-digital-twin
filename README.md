# Probabilistic ERT-Driven Geological Digital Twin for Adaptive Borehole Placement Using Surrogate-Assisted Bayesian Inference

## Project Overview

This project develops a probabilistic geological Digital Twin based on Electrical Resistivity Tomography (ERT). Using synthetic geophysical data, the project investigates how surrogate modelling and Bayesian inference can quantify subsurface uncertainty and support adaptive borehole placement.

## Objectives

- Develop a synthetic 2D geological model with uncertain subsurface structure.
- Simulate ERT measurements using a physics-based forward model.
- Develop and validate a machine-learning surrogate model.
- Perform Bayesian inference to estimate uncertain geological parameters.
- Quantify uncertainty in geological predictions.
- Investigate adaptive borehole placement using uncertainty reduction.

## Project Workflow

1. Geological model construction.
2. ERT survey design.
3. Physics-based forward modelling.
4. Synthetic data generation.
5. Surrogate model development.
6. Bayesian inference and uncertainty quantification.
7. Adaptive borehole placement.
8. Digital Twin concept and evaluation.
