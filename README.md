
# Probabilistic ERT-Driven Geological Digital Twin

## Project Overview

A surrogate-assisted probabilistic 2D geological Digital Twin using Electrical Resistivity Tomography (ERT).

The project investigates how physics-based modelling, machine learning and Bayesian data assimilation can improve uncertainty-aware subsurface characterization.

## Main Components

1. 2D geological modelling
2. Physics-based ERT forward modelling
3. Gaussian Process surrogate modelling
4. Monte Carlo uncertainty quantification
5. Sensitivity analysis
6. Bayesian data assimilation
7. Adaptive survey design using expected information gain

## Technology Stack

- Python
- pyGIMLi
- NumPy and SciPy
- scikit-learn
- SALib
- Jupyter Notebook

## Data

Synthetic geological models and ERT observations.

## Project Duration

Four weeks.
